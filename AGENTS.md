# Flowboard

Dashboard a canvas infinito, in sola lettura, che mostra tutte le schermate Storybook di un progetto JavaScript. Uso e comandi: [README.md](README.md).

## Fine di ogni task

Quando finisci un task, committa e pusha su `main`: il task è finito solo quando il push è riuscito. Se il push viene rifiutato perché il remoto è avanzato, fai `git pull --rebase` e ripeti il push; non forzarlo mai.
